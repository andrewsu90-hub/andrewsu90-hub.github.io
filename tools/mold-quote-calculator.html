🧮 塑膠模具與成型單價估算

依產品尺寸、穴數、鋼材與複雜度估算射出模具開模費用；依件重、投影面積、週期與良率推算鎖模力噸數選機與成型單價。支援 TWD / RMB / USD 幣別切換與模具費攤提。

估算模型：業界通用比例法（模仁材料×加工係數、鎖模力選機、機台噸數費率），結果僅供報價參考

💱 幣別設定（兩個計算區塊共用）

① 模具估價

估算方式

模具價 = 材料費(模仁+模架+標準件) + 加工費 + 設計費 + 試模費 + 管銷利潤 模仁尺寸由產品尺寸與穴數排布自動推算；加工費依複雜度與滑塊/斜頂數量計算
自我檢核：材料費占總價 16%–32% 為業界合理區間，超出時顯示提醒（不影響計算結果）

② 塑膠產品成型單價

估算方式

單價 = (材料費 + 加工費 + 包裝費) × (1 + 管銷利潤) + 模具攤提(選填) 材料費 = (件重 + 水口分攤×(1−回收)) × (1+損耗) × 材料單價 加工費 = 機台費率 × 週期 ÷ 穴數 ÷ 良率；噸數由鎖模力自動選機
週期填 0 時改由壁厚自動估算；機台費率預設由噸數推算，可手動覆寫
