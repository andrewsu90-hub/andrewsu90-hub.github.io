四種基本邊界條件

簡支 Simply Supported

邊緣不能上下移動，但可自由轉動（如置於鉸鏈或平整支架上）。

y = 0, M = 0

固定 / 嵌固 Fixed (Clamped)

邊緣完全夾緊，不能上下移動，亦不能轉動（如焊死或鎖死）。

y = 0, θ = 0

自由 Free

邊緣無任何支撐，完全懸空。

M = 0, Q(V) = 0

導向 Guided

邊緣不能轉動（強制保持水平），但可自由上下滑動。

θ = 0, Q(V) = 0

常見問題 (FAQ)

Q：為何只有「案例 1」與「案例 8」可以選擇中心集中力？
A：本工具依循傳統工程手冊之解析解製表。案例 1（四邊簡支）與案例 8（四邊固定）具備完美的對稱性，偏微分方程式可有效收斂為單純的查表係數（α、β）。

其他非對稱邊界（如三邊固定、一邊自由等）若承受局部集中力，最大應力與撓度發生點會隨長寬比游移，且數學解析解為極複雜的無窮級數，無法被標準化為簡單表格。實務上，針對非對稱邊界的局部集中載荷，建議直接利用如 Creo 等有限元素分析（FEA）軟體進行應力模擬，以求得最精確的結果。
