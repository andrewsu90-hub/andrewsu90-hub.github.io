四種基本邊界條件

簡支 Simply Supported

邊緣不能上下移動，但可自由轉動（如置於鉸鏈或平整支架上）。

y = 0, M = 0

固定 / 嵌固 Fixed (Clamped)

邊緣完全夾緊，不能上下移動，亦不能轉動（如焊死或鎖死）。

y = 0, θ = 0

自由 Free

邊緣無任何支撐，完全懸空。

M = 0, Q(V) = 0

導向 Guided

邊緣不能轉動（強制保持水平），但可自由上下滑動。

θ = 0, Q(V) = 0
